# Machine Learning Course Repository

Day 1 of class 

Welcome to the **Machine Learning Course Repository**!  

This repo is designed to provide a **modular, classroom‑friendly structure** for learning and teaching machine learning.  
It contains Jupyter notebooks, scripts, datasets, slides, and mini‑projects aligned with a step‑by‑step curriculum.

---

## 📂 Repository Structure

- **data/** → Sample datasets (CSV/JSON) for practice  
- **notebooks/** → Jupyter notebooks organized by topic:
  - Part 1: Data Preprocessing  
  - Part 2: Regression (Linear, Polynomial, SVR, Decision Tree, Random Forest)  
  - Part 3: Classification (Logistic, KNN, SVM, Naive Bayes, Decision Tree, Random Forest)  
  - Part 4: Clustering (K‑Means, Hierarchical)  
  - Part 5: Association Rule Learning (Apriori, Eclat)  
  - Part 6: Reinforcement Learning (UCB, Thompson Sampling)  
  - Part 7: Natural Language Processing (Bag‑of‑Words, NLP algorithms)  
  - Part 8: Deep Learning (ANN, CNN)  
  - Part 9: Dimensionality Reduction (PCA, LDA, Kernel PCA)  
  - Part 10: Model Selection & Boosting (Cross Validation, Grid Search, XGBoost)  
- **scripts/** → Reusable Python scripts (preprocessing, visualization, model utilities)  
- **slides/** → Lecture slides (PDF/PowerPoint)  
- **projects/** → End‑to‑end mini projects integrating multiple concepts
